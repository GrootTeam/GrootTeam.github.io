Smaller models.
Serious capabilities.

Groot is a family of four open-weight Mixture-of-Experts models for reasoning, coding and tool use — built from Qwen, GLM and DeepSeek models, then made smaller while keeping the capabilities that matter when there is real work to do.

A note on model sizes. Names follow the model cards' headline parameter conventions, not complete storage or runtime-memory requirements. The 65B release additionally contains a 51B n-gram lookup table and a 1.4B MTP layer; the 280B release additionally contains 197B Engram memory and 14B of MTP/draft layers. The 19B and 238B models also have additional 0.4B and 5.6B MTP layers. Active parameters are not the same as memory usage.

Size against capability

Our reported evaluations across 16 benchmarks, unweighted — not an independent leaderboard. The full per-model charts include the wins and the losses.

Across the 16 evaluation runs, the 19B uses 23.1% fewer output tokens on average than Qwen3.6-35B-A3B, and the 65B uses 28.3% fewer than Qwen3.8-Flash-Next. These are output-token comparisons, not measured latency or throughput improvements.

How to read the results. Agent scaffolds, context limits, reasoning effort and sampling settings differ by benchmark and model; the linked cards document those settings. Hardware-fit examples in the cards are capacity estimates, not a substitute for testing your own workload.
